# Syftet med svetsarprövningen

I detta avsnitt redovisas de delar av SS-EN 287– 1:2011 svetsning av metalliska material, som berör svetsarens åligganden vid certifiering enligt denna tandard. Tabellerna i avsnittet är hämtade ur standarden. Standarden gäller för manuella svetsmetoder, där svet­sarens skicklighet har ett avgörande inflytande på svetskvaliteten, liksom förmågan att följa skriftliga och muntliga instruktioner. Svetsaren skall dessutom ha tillräcklig praktisk erfarenhet av och kunskap om svetsmetoden, materialet som används, samt säker­hetsbestämmelser för vilka han skall godkännas.

Svetsaren som skall certifieras kan avlägga ett s.k. arbetskunnighetsprov (teoretiskt). Provet är baserat på innehållet i ”Bilaga C”, en bilaga till SS-EN 287. Provet på arbetskunskap är inte obligatoriskt. Vissa länder kan dock ställa krav på ett sådant prov.

Provsvetsen kan användas för att kvalificera en  _svets­procedur_ och en  _svetsare_ under förutsättning att alla relevanta (betydelsefulla) fordringar (t.ex. provstyck­ets dimensioner) uppfylls se EN ISO 15614-1.

Svetsmetoder som beröres i denna standard, omfattar de smältsvetsmetoder som betecknas som manuella eller delmekaniserade.
