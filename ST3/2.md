# Slipning och handhavande av volframelektroder

![enter image description here](https://lernia.itslearning.com/data/1821/C2568/Teori%20k%C3%A4lsvets%201/ST%203/ST%203%20bild%201.JPG)

De volframelektroder som används vid TIG-svetsning kan innehålla ämnen som skadar svetsaren, speciellt vid slipning. Vissa studier pekar mot att bl a torium är svagt radioaktivt, och kan orsaka hälsoproblem.

Slipning av volframelektroder innebär därför minst två riskfaktorer för svetsaren:

1. Kringflygande partiklar som kan skada ögon och hudpartier.

2. Slipdamm som svetsaren eller arbetskolleger kan andas in.

För att minimera risken för flygande partiklar är det självklart att svetsaren alltid skall använda skyddsglasögon och handskar.

Det går att montera ett utsug på slipmasinen för att ta bort slipdammet. Detta innebär dock att dammet måste tas hand om vid ett senare tillfälle. Idag finns på marknaden ett antal våtslipmaskiner av skilda märken, speciellt för slipning av volframelektroder. Dessa maskiner slipar elektroden till en inställd vinkel, men det sker inne i maskinen och tillsammans med en vätska. Dammet blandas med vätskan och samlas därefter i en behållare som kan bytas ut när denna är full. Behållaren skall sedan skickas för miljösanering.
