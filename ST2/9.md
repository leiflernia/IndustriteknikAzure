# Rotgaser

Vid TIG-svetsning används ofta en rotskyddsgas för att undvika oxidering av svetsens rotsida (andra sida). Oxideringen kan nämligen nedsätta materialets korrosionsmotstånd och dess hållfasthetsegenskaper. Rotskyddsgas är därför ett absolut krav när det gäller svetsning av höglegerade stål och titan. Även vid svetsning av olegerat och låglegerat stål kan rotskyddsgas ge fördelar. Man undviker till exempel glödskal, som vid krav på högre kvalitet måste slipas bort.

De gaser som används som rotskyddsgas kan vara av två slag,  _inerta_  eller  _reducerande_.

Inerta gaser är som tidigare nämnts  **argon**  och  **helium**, medan de reducerande gaserna består av  **5-10% hydrogen med rest nitrogen**, som förbränner det eventuella oxygen som kan finns kvar på rotsidan.
