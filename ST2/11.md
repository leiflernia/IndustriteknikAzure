# Fel som kan förekomma

Det är inte självklart att gas med den renhet som leverantören garanterar, kommer fram till smältbadet. Orsaker som kan försämra den skyddande funktionen och påverkar svetsresultatet är:

- Vattenläckage i TIG-pistol
- Felaktigt gasflöde
- Dåligt rengjorda gaskåpor
- Otäta kopplingar
- Luftrörelser som stör skyddsgasen
