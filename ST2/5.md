# Svetsning på likström

Vid likströmssvetsning används det en spänning där handtag normalt är kopplad till -pol och återledare är +pol. Likströmmen kan antingen vara rak eller pulsad. Vid svetsning i tunna material, mindre än 1 mm kan det vara värt att polvända och köra elektrod på +pol. Då för att få bättre kontroll på smältan då 70% av värmen hamnar på elektroden istället.

![](https://files.itslearning.com/data/1821/C6330/bilder/Likstr%c3%b6m.png)![](https://files.itslearning.com/data/1821/C6330/bilder/Pulserad%20likstr%c3%b6m.png)

Elektroder som vanligen används vid tig-svetsning likström är

WT-elektroder(wolfram thorium, med vanligast WT20(röd 2% thorium)), dessa är på nedgång då dammet från dem är radioaktivt. Vid slipning skall speciella slipmaskiner användas som samlar upp dammet.

WCe-elektroder används vid låga svetsströmmar, bara för DC

WLa-elektroder fungerar både för DC och AC. WLa med 1.5% lanthan fungerar ungefär lika som en WT20-elektrod. Slipning beror på om DC eller AC. Vid DC, slipas spetsig möjligen med bruten spets. Vid AC skall spetsen brytas av, då för att inte släppa av wolfram till svetsen.
