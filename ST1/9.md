# Kalibrering för att kunna övervaka utstorheterna

![](https://lernia.itslearning.com/data/1821/C2568/Teori%20k%C3%A4lsvets%201/ST%201/ST%201%20bild%207.JPG)Svetsmaskinens inställning avviker ofta från de värden som skalan visar. Genom långvarig användning kan inställningsvredet rubbas, och maskinen visar då något helt annat än det tänkta värdet.

Av den anledningen skall svetsmaskinen kalibreras med jämna mellanrum, d.v.s. det inställda värdet för t.ex. svetsströmmen, skall kontrolleras mot en amperemeter.

**OBS! Koppla bort TIG-strömkällans högfrekvens vid mätning. Annars kan amperemetern förstöras!**

Ett sätt att kontrollera hur mycket av inställd parameter som försvinner genom dåliga svetskablar och söndriga elektrodhållare/återledarklämmor är att mäta spänningen. Vid svetsmaskinens kabelutgång mäts  _arbetsspänningen_, vilken går att ställa i relation till  _bågspänningen_  som mäts vid elektrodhållaren. Börja alltid mätning sedan svetsningen påbörjats.
