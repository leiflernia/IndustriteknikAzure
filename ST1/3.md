# Inställning av svetsström:

**hjälpmedel**

Inställning av svetsström sker vanligtvis genom ett reglage på svetsströmkällan. Strömstyrkan bestäms av arbetsstyckets tjocklek, svetsfogens utförande, svetsläge samt grundmaterial.

Om svetsningen sker på större avstånd från svetsströmkällan kan ett  _fjärreglage_  användas. Det kopplas till ett speciellt uttag på svetsströmkällans front, och med ett reglage leds inställningen från strömkällan till fjärreglaget.
