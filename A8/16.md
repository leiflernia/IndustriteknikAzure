
# Stål och grupperingar

Stål går att gruppera på många olika sätt. I de kommande styckena ska vi gå igenom olika typer av stål och dess grupperingar.

ISO/TR 15608 ger grupperingarna mot hur tidigare svetsarprövningarna delades in.

EN 10025 grupperar mer på hur materialen är sammansatta och behandlade

## Stål grupperat enligt ISO/TR 15608 

* ReH = Högsta sträckgränsen.

* Rm = Brottgränsen.

 

Grupp 1

Stål med legeringshalter enligt följande C≤0,25, Si≤0,60, Mn≤1,8
Sträckgränser enligt nedan

ReH ≤ 275N/mm²
275> ReH ≤ 360N/mm²
Normaliserade stål med ReH >360 N/mm²
Stål med förbättrat motstånd mot korrosion, materialanalys kan ta materialet utanför ovan nämnda specifikationer
 

Grupp 2

Termomekaniskt behandlade finkornsstål och gjutstål

360 N/mm² < ReH ≤ 460 N/mm²
ReH > 460 N/mm²
 

Grupp 3

Seghärdade och utskiljningshärdade stål utom rostfria stål ReH > 360 N/mm²

 

Grupp 4

Lågt vanadinlegerade Cr-Mo-(Ni) stål med Mo ≤ 0,7 % och V ≤ 0,1 %

 

Grupp 5

Cr-Mo stål utan vanadin med C ≤ 0,35 %

 

Grupp 6

Högt Vanadinlegerade Cr-Mo-(Ni) stål

 

Grupp 7

Ferritiska, Martensitiska eller utskiljningshärdade rostfria stål med C ≤ 0,35 % och 10,5% ≤ Cr ≤ 30 %

 

Grupp 8

Austenitiska rostfria stål, Ni ≤ 35 %

8.1       Austenitiska rostfria stål med Cr ≤ 19,0 %

8.2       Austenitiska rostfria stål med Cr > 19,0 %

8.3       Mangan Austenitiska rostfria stål med 4 % < Mn ≤ 19,0 %

 

 

Grupp 9

Nickellegerade stål med Ni ≤ 10,0 %

Nickellegerade stål med Ni ≤ 3,0 %
9.2       Nickellegerade stål med 3,0 % < Ni % ≤ 8,0 %                    

9.3       Nickellegerade stål med 8,0 %< Ni ≤ 10,0 %

               

Grupp 10

Austenit – ferritiska rostfria stål (Duplexa)

Grupp 11

Stål som omfattas av grupp 1 men med 0,25 % < C ≤ 0,85 %
