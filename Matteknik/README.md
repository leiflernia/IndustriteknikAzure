# Introduktion till kursen mätteknik

Området behandlar den kunskap, förståelse och färdighet som behövs för att få teoretisk förståelse för mätningar på producerade produkter och bedöma vilken typ av mätinstrument som är lämpligast att använda. Detta leder till kompetens att ansvara för att fastställda instruktioner följs, att rätt åtgärd utförs samt att identifiera sitt eget behov av lärande.

I kursen kommer du att få börja läsa om inom industrin vanligt förekommande fysikaliska storheter och mätbegrepp för att sedan läsa om mekanisk mätteknik och mätverktyg. Kursen avslutas med kunskapstest.  
  
När du är klar så har kursen gett dig en grundläggande förståelse för  
- Begreppen längd, massa, tid, temperatur etc.
- Förståelse för val av mätmetod avseende vad som ska mätas
- Förståelse för begrepp och mätmetoder för mätning
