# Kombination av grundsymboler

![enter image description here](https://lernia.itslearning.com/data/1821/C34377/svetsbeteckningar/komb02.png)

För att få en mer passande beteckning  kan man kombinera två eller flera grundsymboler.

![enter image description here](https://lernia.itslearning.com/data/1821/C34377/svetsbeteckningar/komb03.png)

Ritningen visar att en svets ska läggas i en U-fog på pilsidan och V-fog på andra sidan.
En sådan svetsbeteckning fodrar ofta en kompletterande måttsättning.

![enter image description here](https://lernia.itslearning.com/data/1821/C34377/svetsbeteckningar/komb04.png)

När fogen är symmetrisk skall den streckade delen av referenslinjen utlämnas. Referenslinjen får det utseende som ritningen visar.

![enter image description here](https://lernia.itslearning.com/data/1821/C34377/svetsbeteckningar/komb05.png)

Beteckningen visar en dubbel J-fog. Om stumfog gäller ska hänvisningslinjen peka på den fogberedda delen.

På pilsidan skall man svetsa i en halv Y-fog.
På andra sidan skall en kälsvets läggas.
