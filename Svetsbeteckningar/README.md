# Inledning

För att svetsaren ska veta hur, var och ibland varför, en svets ska se ut på ett visst sätt, används svetsbeteckningar.
Tidigare använde vi beteckningar enligt Svensk Standard, men från 1987 använder vi en ISO-standard som är lika över nästan hela världen.

Svetsbeteckningar beskrivs i Ritningsregler för Svets- och Lödförband med beteckningen SS-ISO 2553. OBS, *tänk på att använda den senaste utgåvan*.

Svetsbeteckningarna utgöres av grundsymboler, som kan kompletteras med tilläggssymboler, måttangivelser och
kompletterande beteckningar som t ex svetsmetod, svetskvalitet mm.
