# När skall validering göras?

Validering skall utföras innan svetsning där svetspro-cedurspecifikationer används samt vid installation av ny eller renoverad svetsutrustning eller vid misstanke om att inställda värden inte längre stämmer.

_OBS! Koppla inte amperemetern förrän ljusbågen tänts!_

All mätutrustning som skall användas vid validering skall förvaras så att den inte kommer till skada.
