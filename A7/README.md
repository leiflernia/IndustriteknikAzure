# Kontroll av parametrar

**Validering och kalibrering av maskinbe­roende parametrar**

Validering = Bekräfta/intyga funktioners riktighet. (Uppmätt värde.)

Kalibrering = Kontroll och eventuell justering av de mätinstrument som används vid validering.

Det finns ingen standard idag som ställer krav på att svetsmaskinerna skall vara kalibrerade. Det räcker med att redovisa maskinens värden med validering. Detta redovisas metod för metod i detta avsnitt.
