# Arbetsmiljö vid plasmaskärning

**Elektrisk säkerhet:** Slå alltid ifrån strömkällan när du: flyttar återledarfästet, justerar elektrodavståndet, byter skärdys.

**Buller:** Bullernivån vid plasmaskärning ligger på mellan 90–115 dB. Använd hörselskydd.

**Strålningsrisken:** Använd svetshjälm med lägst 11 DIN svetsglas. Använd handskar och tät klädsel som skyddar mot ultraviolett strålning. Använd inte kon­taktlinser, ögonen kan skadas på grund av den inten­siva värmestrålningen.

**Rök och gaser:** Metallrök bildas =använd utsug! Nitrösa gaser bildas när man använder luft, nitrogen eller nitrogenblandningar som skärgas. Ozon bildas när luftens oxygen bestrålas med ultravioletta strålar. Ozon och nitrösa gaser kan ge skador på lungorna.
