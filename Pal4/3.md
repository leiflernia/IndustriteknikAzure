# Metoder för fogberedning 

Fogberedning i aluminium kan göras med plasma- eller laserskärning, bandsåg, cirkelsåg, slipning med slipmaskiner, genom klippning eller mejsling. Tänk på att vid slipning eller kapning att använda skivor avsedda för aluminium.
