# Definition av rakhet för en generatris

En rakhetstolerans på ritning kan se ut så här!

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image079.jpg)

Det betyder att varje generatris på axeln, var för sig, skall vara så rak att den kan få plats mellan två tänkta parallella plan med ett inbördes avstånd på 0,2 mm.

_Generatrisen skall ligga mellan två parallella plan med inbördes avstånd ”t”_

Ska vi då följa toleransen på bilden ovan så motsvarar t 0.2.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image081.jpg)

_Skulle jag svarva en axel som ser ut så här är den inte godkänd_

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image083.jpg)

_Denna axel, däremot, uppfyller rakhetskravet._

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image085.jpg)

Medan en generatris bara kan vara krokig i en riktning kan en centrumlinje vara det åt alla möjliga håll. Vi behöver därför en definition som begränsar formavvikelser i alla riktningar.

_Centrumlinjen skall ligga inom en cylinder med diameter t_
