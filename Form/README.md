<!-- ## Form och Lägestoleranser -->

### SS-ISO 1101 - 2005

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image002.jpg)

Vi har i tidigare kapitel läst om Dimensionstoleranser men det finns även Form- och lägestoleranser.

Form- och lägestoleranser reglerar vilka avvikelser i formen samt läget på en detaljs olika hål och ytor.

### **Dimensionstoleranser tillsammans med form- och lägestoleranser**

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image004.jpg)

För detaljens funktion så har man 2 krav: Dels så ska måttet ”A” ligga inom dimensionstoleransen 0.4 och dels ska ytan var plan inom 0.1 mm.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image006.png)![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image008.png)

Om endast dimensionstoleransen ”A” används måste den sätta efter det strängaste kravet 0.1 mm.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image010.png)![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image012.png)

Med både dimensionstolerans och formtolerans får A variera inom 0.4 Kravet 0.1 gäller endast ytans planhet. Detta medför som regel en lägre tillverkningskostnad.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image014.png)

I den svenska standarden finns det för närvarande 15 olika form och lägestoleranser. Två av dessa har en gemensam symbol.

Form och lägestoleranser anger hur form, riktning, läge och kast får variera.

Dessa ersätter inte dimensionstoleranser utan verkar som ett komplement till dem.
