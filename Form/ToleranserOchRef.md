## Toleranser och referenser för delningsdiameter

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image062.png)

Toleranser och referenser som anges för skruvgängor gäller delningsdiameterns centrumlinje om inte annat anges

**MD** för ytterdiameter

**LD** för innerdiameter

Toleranser och referenser som anger kuggar och splines skall ange det specifika element för vilka de gäller

**MD** för ytterdiameter

**PD** för medeldiameter

**LD** för innerdiameter
