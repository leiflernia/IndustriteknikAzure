# Val av mätmetod

Om en axel kröks påverkas både generatrisens och centrumlinjens rakhet

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image090.png)

Axeln är alltså underkänd både vad gäller rakheten på generatrisen och rakhet på centrumlinjen.

Om en axel tillverkas med form som en tunna eller ett timglas påverkas generatrisens rakhet medan centrumlinjens rakhet inte påverkas.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image091.png)

Denna axeln är oxå underkänd vad gäller rakhet på generatrisen medan rakhet på centrumlinje är godkänd.

Det innebär att det är viktigt att skilja på vilken linje rakheten gäller för när man väljer mätmetod.
