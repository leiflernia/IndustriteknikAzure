# Utflyttat toleransområde

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image056.png)

Ibland kan man behöva sätta tolerans för ett elements förlängning utanför detaljen.

Låt oss anta att pinnar pressas i hål och man vill tolerans sätta läget som dessa pinnar kommer att få. I ett sådant fall är det intressanta var pinnarna ligger utanför själva hålet, inte var hålet i sig finns. Genom att då sätta en tolerans för lägesriktigheten på hålets centrumlinje, men i dess förlängning utanför detaljen, kan man styra att funktionskravet innehålls.
