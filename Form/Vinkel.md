# Vinkelräthet

Det som skiljer vinkelräthet från parallellitet är enbart att toleransområdet vid vinkelräthet ligger i 90° mot referenselementet medan det vid parallellitet ligger 0° mot referenselementet.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image111.jpg)

Om toleransvärdet föregås av ett diametertecken ska linjen ligga inom en cylinder med diametern T (0.1) som är vinkelrät med referenslinjen.

Linjen ska ligga mellan två parallella räta linjer på avståndet T (0.1) från varandra, vilka är vinkelräta med referenselementet.
