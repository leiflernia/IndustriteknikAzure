Pilen pekar på det toleranssatta elementet.

Toleranssymbolen berättar vilken tolerans det gäller och i detta fallet är det parallellitet.  
  

Toleransvärdet berättar hur stor toleransen är. Den anges i samma enhet som de linjära måtten. Som i detta fallet så är det ett Ø mått som är angivet. Men skulle lika väl kunna vara ett SØ om det skulle vara ett cirkulärt mått eller om det hade varit ett linjärt så hade det bara stått 0.01.  
  

Referensbokstaven talar om i förhållande till vilken yta som man ska ha att referera till.  
Här är det viktigt att vara noga och kolla till viken yta vi refererar.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image034.jpg?)

**Tolerans för en grupp**

Om toleransen gäller för mer än ett element, till exempel en grupp av 5 hål, skall detta anges i text ovanför toleransrektangeln som på bilden (5X)

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image035.jpg?)

**Kompletterande krav**

Kompletterande krav för elementet kan skrivas nära toleransrektangeln och vid behov förbindas med en hänvisningslinje.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image032.png?)

**Flera krav för samma element**

Man kan ange mer än en toleransegenskap för ett element och då kan toleransrektanglarna

placeras under varandra. Detta innebär **inte att de båda kraven har något annat inbördes samband** annat än att bägge, var för sig, gäller för samma element.
