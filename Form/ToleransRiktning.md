# Toleransområdets riktning

I normalfallet är toleransområdet för ett verkligt element vinkelrätt mot specificerad geometri.

Om man inte avser att toleransområdet skall gälla vinkelrätt mot ytan på ett verkligt element skall man sätta ut mätriktningen på ritning.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image059.jpg)

Toleransen, och därmed mätriktningen, gäller **vinkelrätt mot ytan i varje snitt för sig**

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image061.jpg)

_Toleransen, och därmed mätriktningen, gäller **50° mot ytan i varje snitt för sig.**_
