# Symmetri

Används när ett symmetrielement, som till exempel ett mittplan mellan två ytor, skall ligga symmetriskt med ett annat symmetriplan. Det innebär att toleranssatt element skall centrera med referensen, alltså en liknande tolerans som koaxialitet. Skillnaden mellan dessa är att koaxialitetstoleransen enbart används för cylindriska element medan symmetritoleransen kan användas för andra typer av element som mittplan och mittlinje.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image120.png)

Den toleranssatta linjen/centrumlinjen ska ligga mellan två parallella räta linjer på avståndet T (0.1) från varandra, vilka är symmetriskt belägna omkring referenslinjen/referensplanet.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image121.png)

Hålens symmetrilinje (svarta) ska ligga mellan två parallella linjer (orange). Dessa ligger 0.05 mm på vardera sida om ytterkonturens symmetrilinje (blå).
