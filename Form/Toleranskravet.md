# Toleranskravets anslutning

Pilen ansluter till en konturlinje eller dess förlängning. Det innebär att toleranserna gäller verkliga element, det vill säga den yta som pilen ansluter till.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image038.jpg?)

Om toleransen gäller ett elements centrumlinje eller mittplan, görs anslutningen normalt genom att peka mot måttlinjen.
![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image040.jpg?)

Det är alltså mycket viktigt att vara observant på var pilen ansluter. Är det mitt för en måttlinje på en axel gäller toleransen för en centrumlinje men flyttar man pilen någon mm åt sidan, så att den ansluts till konturlinjens förlängning, så har man ändrat innebörden till att istället gälla en generatris.
