
## Termer och grundläggande definitioner


![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image018.jpg)![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image020.jpg)

**Generatris.**

En generatris är en rät linje på kroppens yta, som dras i kroppens längdriktning.  
  

**Mantelyta.**

Är ytan på ett cylindrisk objekt som hål eller axel.  
  

**Verkligt element.**

Ett element som går att ta på, verklig fysisk del av en detalj. Ett plan kan vara ett verkligt element liksom en mantelyta.

**Overkligt element.**

Ett av en verklig yta bildat element som inte finns fysiskt. Ett overkligt element går inte att ta på direkt. Typiska exempel på overkliga element är centrumlinjer eller mittplan (symmetriplan).

Element kan vara toleranssatta eller användas som referens.  
  

**Tangerande plan.**

Ett tänkt perfekt plan som tangerar ett verkligt plan på en artikel. Lägger man en artikel på en planskiva utgör planskivan tangerande plan mot artikeln.  
  

I exemplet ovan visas en axel. Mantelytan kan sägas bestå av en mängd generatriser. Både mantelytan och generatriserna är verkliga element. Centrumlinjen däremot är ett overkligt element.  
  

**Minsta inskrivna cylinder.**

Den minsta möjliga perfekta cylinder som kan träs över en axel.

**Största inskriva cylinder.**

Den största möjliga perfekta cylinder som kan föras in i ett hål.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%c3%a4gestoleranser/image023.png)

**Parallella linjer och ytor.**

Räta linjer och plana ytor som överallt har samma avstånd mellan sig.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/Form%20och%20l%C3%A4gestoleranser/image025.jpg)


**Jämlöpande linjer och ytor**

Krökta linjer och krökta ytor som överallt har samma avstånd mellan sig. Observera att krokiga linjer och oplana ytor **inte är parallella i form- och lägesystemet utan kallas jämlöpande trots att** de har samma avstånd mellan sig överallt. Ordet parallell är reserverat för raka linjer och plana plan!

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image027.jpg?)

**Koaxialitet**

Två cylindrar som har **samma centrumlinje kallas koaxiala.**

**Koncentricitet**

Två cirklar som har samma centrumpunkt kallas koncentriska.
