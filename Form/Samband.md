### Samband mellan form-, riktnings- och lägestoleranser

För att åskådliggöra hur form- och läges systemet är uppbyggt skall vi titta på hur man kan tolerans sätta ett plan. Låt anta att vi skall tillverka en detalj som ser ut så här.

_Måttsättning 1:_
_Enbart dimensionstolerans_

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image123.jpg)![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image125.jpg)

Vi har gjort följande fyra detaljer där det finns olika typer av avvikelse på det övre planet. Vi skall titta på hur fyra olika måttsättningar påverkar bedömningen av detaljerna. Toleransområdet för dimension ritas i lila.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image127.jpg)
_Måttsättning 2:_
_Dimensionstolerans kompletterad med en formtolerans_

Skulle man måttsätta såhär istället med planhet.  Toleransområdet för planhet begränsas av två parallella plan med avstånd 0,1 mellan sig. Fortfarande ligger alla detaljerna inom dimensionstoleransen.(0,2)

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image128.png)

Vad gäller planhetskravet är detaljerna 2, 3 och 4 godkända medan detalj 1 inte ryms inom toleransområdet.

Observera att en planhetstolerans inte har något samband med resten av detaljen. Detalj nummer två är alltså godkänd eftersom toleransplanen får riktas hur som helst, bara planet får plats innanför är detaljen OK.

Toleransområdet för dimension ritas i lila medan form- och lägestoleranser får sina toleransområden beskrivna med röd färg.

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image130.jpg)
_Måttsättning 3:_
_Dimensionstolerans kompletterad med en riktningstolerans_

![enter image description here](https://lernia.itslearning.com/data/1821/C33238/Bilder/Form%20och%20L%C3%A4gestoleranser/image132.jpg)

Skulle vi istället använda symbolen för parallellitet så blir toleransområdet för parallellitet samma som för planhet, toleranssatt plan skall rymmas mellan två parallella plan på inbördes avstånd 0,1 mm.

Men skillnaden är att toleransområdet vid parallellitet dessutom skall vara parallellt med referensen.

**_För våra fyra detaljer innebär det att_**  nummer 1, som inte fick plats innanför toleransområdet ens när det fick riktas på gynnsammast sätt, naturligtvis inte får plats när en bestämd riktning är föreskriven heller. Nummer 3 och nummer 4 får plats innanför toleransområdet och är godkända medan nummer 2 nu blir underkänd eftersom toleransområdet inte får vridas till gynnsammaste riktning utan måste vara parallellt med referensen.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image134.jpg?)
_Måttsättning 4:_
_dimensionstolerans ersatt av en lägestolerans_

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image136.jpg?)

Även vad gäller lägesriktighet för ett plan består toleransområdet av två parallella plan mellan vilka toleranssatt plan skall ligga.

Dessa skall inte bara vara riktade parallellt med referenselementet utan också belägna symmetriskt runt **teoretiskt riktigt läge.**

Med en lägesriktighet för ytan ersätts dimensionstoleransen av ett teoretiskt läge eftersom dimensionen nu ingår i form- och lägestoleransen.

Med denna måttsättning är enbart nummer 3 godkänd.

![enter image description here](https://lernia.itslearning.com/data/1821/c33238/Bilder/form%20och%20l%C3%A4gestoleranser/image138.jpg?)

I standarderna beskrivs förhållandet mellan de olika grupperna av form- och lägestoleranser så att formtoleranser begränsar formavvikelser, riktningstoleranser form- och riktningsavvikelser medan lägestoleranser begränsar form- riktnings- och lägesavvikelser.
