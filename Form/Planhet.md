# Planhet

Ytan ska ligga inom ett område som begränsas av två parallella plan på avståndet (0.1) från varandra.

Planhet är en formtolerans som används för plana ytor.

Planhet kan också sättas för ett overkligt element i form av ett mittplan, men det är en ovanlig toleranssättning som främst används tillsammans med måttjämkning som ju inte kan användas vid verkliga element och alltså normalt inte används tillsammans med planhet.

Planhet kan sägas motsvara rakhet för generatris men i tre dimensioner istället för bara två.
