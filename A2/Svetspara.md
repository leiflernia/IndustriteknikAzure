# Svetsparametrar

Parameter betyder storhet. Vid svetsning används ordet för att sammanföra alla inställningar som är nödvändiga, och man skiljer därvidlag på utrustningsberoende och personberoende. Vid MMA-och TIG-svetsning är det i första hand svetsström, spänning och polaritet som är utrustningsberoende medan framföringshastighet och ljusbågens längd är personberoende. Vid MIG/MAG-svetsning tillkommer dessutom utrustningsberoende parametrar som induktans, elektrodmatning (ström) samt gasflöde.
