
# Metoder för fogberedning

I svetslitteraturen står: "Fogberedning skall utföras på så sätt att ingen skadlig inverkan på stålets egenskaper uppstår".

 

Fogberedningen kan således utföras genom klippning, kapning, fräsning, plasmaskärning etc. utan att några speciella åtgärder behöver vidtas.

 

Sker fogberedningen däremot med metoder som alstrar mycket värme, t ex pulverskärning, kan ytskiktet uppkolas, det vill säga tillföras extra mycket kol, och då måste kapytorna slipas till dess den uppkolade zonen avlägsnats.

 

Luftbågmejsling skall inte användas för rostfritt stål.

 

Gasskärning går ej att utföra i rostfritt stål.
