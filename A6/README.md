# Svetsningens utförande

**Mål:**

Förstår hur man arbetar efter ett svetsdatablad (WPS) med kunskap om svetsparametrar.

**Omfattning:**

-   Svetsdatablad (WPS) (ISO 15609-1)
-   Svetsparametrar, Svetslägen(ISO 6947)
-   Svets- och förbandstyper: egenskaper, storlek, ytbeskaffenhet
-   Svetsbeteckningar enligt ISO 2553

**Förväntat resultat:**

1.  Läsa Svetsade detaljer på en ritning och tyda svetsbeteckningen (ISO 2553).
2.  Känna till svetslägen enligt ISO 6947.
3.  Känna igen förbandstyperna: T-förband, Överlappsförband, hörnförband, etc.
4.  Känna till kälsvetsen: dimensioner, form, häftsvets och svetsråge.
5.  Känna till användningen av svetsdatablad (WPS) i tillverkningen.
6.  Beskriva Hur man når (ställer in) de krävda parametrarna.
