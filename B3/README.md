# Innehåll och förväntat resultat

### Mål:
Kunna inverkan av svetsvärmen på stål.

### Omfattning:

- Begreppet svetsbarhet
- Inverkan av sammansättning, godstjocklek och temperatur (förhöjd arbetstemperatur och mellansträngstemperatur)
- Sträckenergi

### Förväntat resultat:

<ol type="1">
  <li>Ange inverkan av legeringsämnen på svetsbara ståls egenskaper.</li>
  <li>Beskriv inverkan av godstjocklek på svetsbara ståls egenskaper.</li>
  <li>Redogör för kolekvivalenten och dess användning.</li>
  <li>Beräkna sträckenergin och berätta om dess användning</li>
</ol>
