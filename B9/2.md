
# Betydelsen av kontroll och kvalitetssäkring

Kvalitetssäkring innebär att arbeta systematiskt och planerat för att skapa garanti att produkten uppnår önskad kvalitet. Hela processen från konstruktion via inköp, tillverkning, kontroll/provning till leverans skall kvalitetssäkras. För att säkerställa detta bygger företaget upp ett kvalitetssystem.
