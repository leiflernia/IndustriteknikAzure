# Förstörande provning - Brytprovning


Vid undersökning av ett svetsförbands homogenitet efter brott används brytprov för att utröna förekomsten av defekter såsom slagg, porer och bindfel. Vid svetscertifiering enligt SS-EN ISO 9606 kan radiograferingen ersättas med brytprovning (gäller för stumsvetsning av rör eller plåt). Brytprov vid kontroll av källsvets, endast en sida svetsas.


Hela inspektionssträckan kan delas upp i fyra mindre bitar. Svetsrågen kan slipas bort.
