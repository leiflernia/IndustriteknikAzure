
# Tillsatsmaterial samt standardisering för aluminium

MIG-svetsning utförs alltid med tillsatsmaterial, medan TIG-svetsning kan utföras både med och utan.

Det är viktigt att man väljer rätt tillsatsmaterial för att erhålla de bästa egenskaperna med avseende på hållfasthet, korrision samt för att undvika sprickor.

Som tillsatsmaterial vid aluminiumsvetsning av olegerade och ej härdbara legeringar används artegna material, d.v.s. så lika grundmaterialet som möjligt.

Härdbara legeringar svetsas med tillsatsmaterial som har höga halter av av kisel (Si) eller mangan (Mn). Detta för att undvika varmsprickor.
