# Kalibrering för att kunna övervaka inställda värden

Svetsmaskinens inställning avviker ofta från de värden som skalan visar. Genom långvarig användning kan inställningsvredet rubbas, och maskinen visar då något helt annat än det tänkta värdet.

Av den anledningen skall svetsmaskinen  _valideras_  med jämna mellanrum, d.v.s. det inställda värdet för t.ex. svetsströmmen, skall kontrolleras mot t.ex. en amperemeter.

Ett sätt att kontrollera hur mycket av de inställda värdena som försvinner genom dåliga svetskablar och söndriga elektrodhållare/ återledarklämmor är att mäta spänningen.

Vid svetsmaskinens kabelutgång kan man mäta arbetsspänningen, vilken går att ställa i relation till bågspänningen som mäts vid elektrodhållaren.
