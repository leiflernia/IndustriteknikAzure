# Primära och sekundära strömkretsar

**Skydd för nätet**

Den strömkrets som leder från vägguttaget till svetsmaskinen kallas primärkrets (prima = det första på latin) medan den strömkrets som leder från svetsströmkällan till arbetsstycket kallas sekundärkrets (sekunda = det andra).

För att inte snedbelasta nätet fördelas strömmen oftast över tre faser (utom vissa svetstransformatorer och vissa svetsinvertrar med hög verkningsgrad). Om svetsmaskinen överbelastas bryts strömmen genom att säkringarna över en eller flera faser utlöses. Det är därför viktigt att använda rätt typ av säkring (står på svetsströmkällans märkplåt). Används för kraftig säkring hinner strömkällan skadas innan säkringen ”går”.
