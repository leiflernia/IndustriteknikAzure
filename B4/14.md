# Mekaniska åtgärder

En första förebyggande åtgärd för att reducera deformationer är noggrannhet med tillpassningen av svetskonstruktionens delar. Dålig tillpassning ger stora svetsfogar/spalter och stor värmetillförsel med kastningar och krympspänningar som följd.

Dålig passning ger också stora inbyggnadsspänningar som kan utlösas om materialet utsätts för större påkänningar än vad som avsetts.

Med stigande temperatur blir metaller lättare att forma då sträckgränsen sjunker. Detta går att utnyttja för att korrigera deformationer – tillsammans med mekanisk kraft. Vid svårare fall av krympspänningar och deformationer kan det vara enda möjligheten att åstadkomma ett tillfredsställande resultat.

Vid ett sådant arbete kan användas hjälpmedel som kilar, spärrblock, domkrafter o dyl.
