# Uppkomst av deformationer
 

Deformation och krympning (materialet ”kastar” eller ”slår sig”) kan minimeras om storleken av formförändringen kan förutses. De första åtgärderna sker redan vid upphäftning, då arbetsstyckets delar kan placeras så, att de efter svetsningen befinner sig i rätt läge.
