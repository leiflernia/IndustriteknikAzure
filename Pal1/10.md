# Metoder för att eliminera hälsofaror

Vid fogberedning av aluminium genom slipning eller kapning skall ögon- och andningsskydd användas. Vid svetsning skall punktutsug användas för att leda bort svetsröken. Svetsvisir med friskluftstillförsel är ett utmärkt komplement för att skydda mot de stoft och gaser som inte punktutsuget förmår avlägsna.

Bågsvetsning i aluminium genererar betydligt mer ozon och ultraviolett ljus än vid svetsning av andra material, detta på grund av den reflekterande ytan. Ozonhalten kan nedbringas om man t.ex. använder skyddsgaser med tillsatser av NO2 eller helium.
