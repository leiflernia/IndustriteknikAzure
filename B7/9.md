	
# Jordning (återledning)

Svetskretsens återledare skall alltid fästas så nära svetsstället som möjligt. Ju längre avstånd från svetsmaskin till svetsställe, desto större risk för att svetsströmmen tar oväntade och ibland förödande  omvägar.

Till exempel kan svetsströmmen sätta skyddsjord ur funktion, förstöra elektriska ventiler, bränna sönder lyftvajrar etc. Var särskilt uppmärksam vid återledning i armering.
