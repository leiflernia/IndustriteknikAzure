
# Miljön på arbetsplatsen


***Särskilda problem vid utomhusarbete, arbete på hög höjd, arbete vid dåliga markförhållanden, vid extrem värme, kyla eller blåst***

Ofta utförs större delen av ett svetsarbete på verkstad, men den slutliga sammansättningen kanske måste utföras som montagearbete. Att arbeta på byggarbetsplatser (montage) ställer speciella krav på svetsningens utförande, men också på svetsarens arbetsmiljö. Arbetet påverkas ofta negativt av orsaker som vind, nederbörd, temperatur samtidigt som det finns riskfaktorer som höga höjder eller rasrisker m.m. i schakt och diken.
